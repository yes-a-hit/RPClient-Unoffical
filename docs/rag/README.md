# RPClient UV · RAG 知识库

这是本仓库的**检索用文档集**。它不是给新读者从头读到尾的手册，而是给「先检索、再回答」的场景准备的：每篇只讲一个面，标题和开头一句就能判断要不要细看。

## 为什么要有这一套

仓库本身有 900+ 个 Kotlin 文件。把整棵树塞进上下文既贵又噪声大，模型还容易看到过期实现（同一功能常有旧路径残留在注释和死代码里）。这套文档的做法是：**先把「现在的真相」写成人能核对的几句话，再指回具体文件**，检索时先读文档，需要细节再按路径去读源码。

代价是文档会过期。所以每篇末尾都有「最后核对」标记，改动了对应模块就顺手更新那一篇——这不是额外的礼貌，是这套东西唯一的保鲜手段。

## 三条阅读前提

1. **本分支（UV）不是上游的镜像。** 上游 `KafuuNeko/RPClient` 的三次大重构（拆主页、拆 ViewModel 模型、公共 widget 迁到 `PageSurface` 体系）我们没跟，整包合并已失败两次。文档描述的是**本仓库实际在跑的实现**，不要拿上游代码来对。
2. **`upstream/*` 分支只当参考源。** 想借某个提交，先确认它改的文件在本仓库存在且没被本地改写过，否则会连环冲突（见 07 篇）。
3. **路径一律带目录前缀。** `ChatViewModel.kt` 这种裸文件名在仓库里有多个同名文件，检索时会撞。

## 文档边界

不写这些：版本更新日志（看 `git log`）、待办清单（看 `TODO.md`）、上游功能对比（看 `README_UV.md`）。这三处各有自己的维护者，重复一份只会互相打脸。
